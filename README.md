# 🍔 RecipeNest

RecipeNest is a modern Android Recipe App built using Jetpack Compose in Android Studio.

---

# ✨ Features

- Splash Screen
- Modern UI Design
- Bottom Navigation
- Search Functionality
- Featured Recipe Banner
- Categories Section
- Recipe Detail Screen
- Favorite Toggle
- Favorites Screen
- Profile Screen
- Dark Mode
- Responsive Layout
- Jetpack Compose UI

---

# 🛠️ Technologies Used

- Kotlin
- Jetpack Compose
- Android Studio
- Material 3
